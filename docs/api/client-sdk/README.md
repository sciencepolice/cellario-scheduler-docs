Requests](05-troubleshooting.md#api-request-issues)\n\n## 🏗️ Architecture Overview\n\nThe Cellario Client SDK follows these key principles:\n\n- **Auto-Generated**: Client is generated from OpenAPI specification, ensuring it stays current with API changes\n- **Strongly Typed**: All endpoints, models, and enums are strongly typed for compile-time safety\n- **Async First**: Full async/await support with optional synchronous methods\n- **Authentication Built-in**: Integrated JWT token and basic authentication support\n- **Comprehensive**: Complete coverage of all Cellario API endpoints\n\n## 📋 Requirements\n\n- **.NET Version**: .NET 8.0 or higher\n- **Cellario Version**: 4.5.x (client version should match server version)\n- **Network**: HTTP/HTTPS access to Cellario server\n- **Authentication**: Valid Cellario user credentials with API access\n\n## 🚦 Quick Start Checklist\n\n- [ ] Install Cellario.Client NuGet package\n- [ ] Create CellarioClient instance with
