# What is Scripting?

Cellario Scripting enables operators to define custom logic for Cellario protocol and Auto-recovery operations. Scripting opens a wide range of new possibilities such as dynamically changing scheduling, improving error recovery, and adding custom operations.

Cellario provides a library of scripts, which can be copied into a protocol or used in auto-recovery operations.

# Why C#?

C# (pronounced "see sharp") is an elegant and type-safe object-oriented language that enables developers to build a variety of secure and robust applications that run on the
.NET Framework.

Cellario's scripting engine targets .NET 8 and supports modern C# syntax. There is a large range of books and online resources for learning C#.

:::hint{type="success"}
In Cellario 4.1 Support was added for Python scripting so users can now select in Cellario if they would like to use Python or C#. This decision is made at the script level so you can use a mix of Python and C# scripts within a single protocol.
:::
