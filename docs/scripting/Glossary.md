| **Term**       | **Definition**                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| css\_reference | A call used to create a reference to an external assembly                                                                                                                                                                                                                                                                                                                                            |
| Device         | Any component of a HighRes system that can be involved in a protocol <br />These include the robotic arm, barcode scanner, storage resources (even static nests and the waste location), and any lab instruments that interface with Cellario. Any electronic device that Cellario controlls has a *device driver*.                                                                                  |
| Device driver  | A software component that lets Cellario control a device automatically<br />Drivers can be built as .dll files which expand Cellario, or an executable program that communicates to Cellario from a separate computer. A device driver exposes a list of operations to Cellario and contains code for executing those operations, registering errors, and opening a connection to the device.        |
| GAC            | **G**lobal **A**ssembly **C**ache, a machine-wide shared assembly cache                                                                                                                                                                                                                                                                                                                              |
| .NET Framework | (Pronounced "dot net") is a software framework developed by Microsoft that runs primarily on Microsoft Windows.                                                                                                                                                                                                                                                                                      |
| Operation      | A function of a device<br />Every device can perform at least one operation, some of which are exposed to Cellario’s Protocol Designer, but additional maintenance-related operations can be included in the driver. Protocol-available operations include Read, Dispense, Wash, LiquidTransfer, and Incubate. Some maintenance-related operations include Home, Calibrate and Show Diagnostic Info. |
| Order          | A specific instance of a protocol<br />An order contains all the information in a protocol as well as labware types, quantities, and their locations in storage.                                                                                                                                                                                                                                     |
| Parameter      | A named variable related to an operation<br />Most operations have at least one *parameter*. Parameters may be optional or required, and are always passed by Cellario to the driver as strings.                                                                                                                                                                                                     |
| Plate thread   | Inter-dependent operation sequences that start with an input plate<br />Simple plate threads could contain only one operation (for example, Read). More complex threads could contain hundreds of operations that define a complex experiment.                                                                                                                                                       |
| Protocol       | The definition of the sequence of operations to be carried out on one or more *plate threads* in a workflow                                                                                                                                                                                                                                                                                          |
| Resource       | A system component used to perform an operation or part of an operation<br />A *device* assigned to an *operation* in a *protocol* is considered a resource for that protocol.                                                                                                                                                                                                                       |
| Step           | An operation within a protocol<br />The first step of every thread is the Plate operation, which removes the plate from storage.                                                                                                                                                                                                                                                                     |
