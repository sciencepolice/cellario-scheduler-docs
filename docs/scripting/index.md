# Scripting

Scripting documentation for the Cellario Scheduler. It covers how scripting works,
step-by-step tutorials, and a full reference for the scripting API.

- **Introduction** — an overview of scripting, script structure, and library management.
- **Base Tutorials** — hands-on walkthroughs, from Hello World to using and configuring scripts.
- **Advanced Topics** — deeper material such as referencing dependencies.
- **Scripting API** — reference pages for the API objects (protocols and orders, systems and inventory) and general capabilities.

Sample scripts live in `docs/scripting/samples/` (C# and Python) and are embedded into
pages with `use{file="scripting/samples/...#l1-l20" syntax="csharp"}`.
